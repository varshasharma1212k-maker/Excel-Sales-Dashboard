# End-to-End Excel Sales Dashboard

## Overview
An interactive sales dashboard built in Microsoft Excel to analyze sales performance, target achievement rates, and city-wise metrics across multiple sales executives.

## Preview
![Dashboard Preview](Screenshot%202026-10-03%20180849.png)

## Key Features
- **City Filtering:** Dynamic navigation for top metro cities (Chennai, Delhi, Mumbai, Nagpur, Patna, Pune, Ranchi, Surat).
- **Executive Performance:** Tracks total sales volume per representative.
- **Target Tracking:** Analyzes percentage hit vs. gap away from target.
- **Visual Analytics:** Bar charts, pie charts, and trendlines for clear data interpretation.
